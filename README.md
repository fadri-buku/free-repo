# free-repo

A small collection of self-contained tools. Each feature lives in its own
top-level folder and is documented under [`docs/`](./docs/overview.md).

## Features

- **[Worklog Pomodoro](./worklog/)** — Chrome extension with a pomodoro-style
  countdown timer that locks Chrome when time's up and appends a free-text
  worklog entry to a file you choose.
  See [`docs/features/worklog.md`](./docs/features/worklog.md).
- **[Bukuagen Landing Page](./bukuagen-landing-page/)** — static single-page
  marketing site for the Bukuagen K1, a titanium everyday-carry (EDC) tool.
  Plain HTML/CSS/JS, no build step.
  See [`docs/features/bukuagen-landing-page.md`](./docs/features/bukuagen-landing-page.md).
